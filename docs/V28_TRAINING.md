# V28 TRAIN collection and spatial fitting

Run `python -m adaptive_vcm.train_motion --task ar --root <TRAIN-source-root> --config configs/v28_screen.json --count 128 --epochs 4 --width 12 --seed 302801 --out <new-output-directory>`. For OD, use `--task od` and add `--annotations <COCO-instances-json>` to locate images. Annotation boxes and labels never enter the fitting objective. The annotation file is used by the existing source planner; frozen MobileNet predictions supply OD protection and guards.

Every selected TRAIN source has ten measurement records: H.264 and H.265, each at QP 30, 35, 40, 45 and 50. There is no independent SGD measurement budget. Source pixels, source teacher predictions, semantic/box protection and motion support are prepared once per source. The original controls use their original protection recipe. Each group measures all twelve reference profiles and the original controls with StandardCodec; identical pixel inputs may reuse their exact stream and identical streams reuse decoded teacher predictions.

The target is a reference profile only when its decoded teacher guard passes, it saves at least 1% of anchor bytes, and its actual bytes are strictly below the guarded control winner. Otherwise the target is the original source RGB. A control image is never substituted as an identity target. Unknown OD foreground makes every profile and control retain source identity. Anchor-identical streams always receive finite zero distances and true decisions, including unknown OD.

`cache/sources/<source-index>.npz` stores uint8 THWC source, float32 THW protection and motion, bool T cuts and JSON metadata. Positive targets alone occupy `cache/targets/<measurement>.npz`; identity targets reference their source cache. `measurements.jsonl` binds source ID, pixel shape/hash, support/cache hashes, configuration/code hashes, every actual byte count and stream hash, guards, the control winner, target choice and target hash. The original source T*H*W is the bit-rate denominator. `validate_training_records` checks unique TRAIN provenance and the complete matrix, using `coco2017/<id>` for OD partitioning.

Adam fits a fresh spatial renderer with RGB mean squared error at a fixed learning rate of 0.001. Every epoch visits every measured group once, in a seeded order. QP>=40 losses have weight two; other losses have weight one. Cached uint8 data stays on disk and only the current example is transferred to the device. `train.jsonl` records loss, gradient norm and rounded output/target edit fractions. `epochs.jsonl` reports each epoch's mean loss and gradient norm, pixel-weighted edit fractions, and positive/identity target counts. Fitting uses neither the codec nor teachers, labels, independent evaluators or DEV/TEST data.

The final-LAST `preprocessor_last.pth` records the completed measurement count, epochs and update steps, TRAIN IDs and fingerprint, each source pixel hash, the full code manifest, matching training configuration, measurement hash, profile registry and ten static K=3 orders. Source-content hashes support rejection of renamed TRAIN pixels in evaluation. The static comparator greedily maximizes complementary actual byte savings beyond guarded controls separately for each codec/QP. Unsafe profiles earn zero credit. Static orders and reference profiles are component comparisons; they do not expand the primary learned inference proposal budget.

These artifacts establish collection and fitting provenance. Teacher-feasible TRAIN targets do not establish held-out quality, learned inference feasibility or a BD-rate gain.
