> For agentic workers: use Superpowers TDD and independent requesting-code-review; Arbor executors run in isolated worktrees.

Goal: deliver a runnable learned spatial preprocessor and measured TRAIN/evaluation path for both OD and AR.

Architecture: encoder-only motion/semantic support drives a full-resolution neural blend. Complete TRAIN grids provide actual-codec feasible imitation targets; inference probes three learned outputs alongside unchanged controls.

Tech stack: Python, NumPy, OpenCV Farneback, PyTorch, existing FFmpeg libx264/libx265.

Spec: `docs/superpowers/specs/2026-10-06-v28-motion-design.md`.

Global constraints: V27 remains untouched; no test-split optimization, no crop geometry changes, no side bits, two codecs/five QPs, strict existing guards, no untrained evaluation, final-LAST fitting only.

Review focus: camera pans without foreground motion; segment transitions; T=1 with several tiny objects; infeasible target and all-identity training; malformed checkpoint/grid and oracle leakage.
